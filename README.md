I build data and machine learning pipelines in Python, mostly on Apple Silicon with local models. I like problems where the hard part is knowing whether the answer is any good: how to measure it, what to compare it against, and when a difference is just noise.

I also build the guardrails that let AI coding agents work in my repos safely. The agent writes the code. I own the decisions and every commit.

Most of my repos are private, so here's what's behind the green squares:

- 🧪 **mGlu7 cross-subtype activity:** can data-rich receptor subtypes improve potency prediction for a data-poor one? ChEMBL, RDKit, scikit-learn, and a permutation test to separate signal from noise.
- 🩺 **NPI match:** a matching and recommendation engine over the public US physician registry, scored by recall@10.
- 📄 **Refine Resume:** a local model tailors my resume and cover letter to a job posting, and every claim gets traced back to a source.
- 🥾 **AT Trekker:** a live Appalachian Trail map fed by a Garmin satellite tracker, with pace-adjusted arrival estimates.
- 💙 **National Autism Peer Support:** the website for a non-profit, published entirely through the WordPress REST API.
- 📰 **Daily Brief** *(early stage)*: a news brief written by a local model and delivered before 6am.
- 🐿️ **Squirrel Sentry** *(design stage)*: a humane, motion-triggered way to convince attic squirrels to move out.
